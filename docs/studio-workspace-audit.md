# Studio — аудит рабочего пространства 25.11.2026

Срез: main 585de97d, Studio 0.6.2. Roadmap 3.0, пакет 15; изменение оболочки, не новый runtime. Сверено с файлами site/studio, map, quest, npc, object-library и CI. Функциональность внутри каждого редактора ещё не проверена целиком в браузере.

## Макроуровень: владельцы данных и переходы

| Модуль | Ответственность сегодня | Выход / связь | Граница |
|---|---|---|---|
| Studio | Маршруты iframe, журнал, Roadmap, локальные счётчики | Снимок v1, запуск опубликованного билда | Не редактор данных и не публикация черновиков |
| Geo Lab | Геометрия и стабильные ID | GeoJSON, localStorage → Quest Lab, импорт в Godot | География, не сценарии |
| Quest Lab | Цели, находки, записи персонажей и размещения | JSON, ссылки на geo ID и модели | Слой карты читает Geo Lab, не редактирует исходную географию |
| Model Lab и генераторы окружения | Создание моделей | GLB / IndexedDB → Quest Lab | Не создают игровое размещение сами по себе |
| NPC Lab | Предпросмотр модели и экспорт профиля | JSON вручную | Не полноценный редактор персонажей; связь с каталогом Quest Lab требует отдельной проверки |
| Object Library | Хранение моделей и размещений | IndexedDB chernozerye-object-library v2 | Не отдельная копия каталога для каждого генератора |
| Build Control | CI, экспорт Godot, Pages | Публичный неизменяемый снимок по SHA | Локальный черновик не публикуется автоматически |

Микропоток: редактор сохраняет проверенный черновик → другой модуль читает согласованную схему и ID → QuestGeoOverlayRefresh обновляет геослой и библиотеку при открытии Quest Lab → снимок / экспорт → проверка импорта → отдельная сборка. У каждого редактора собственные данные; одинаковая карта в Geo/Quest не означает дублирование владельца.

## Найденные проблемы

- Обработчики rail-toggle и transitionend регистрировались внутри show(), росло число вызовов. Перенесены в одноразовую инициализацию.
- NPC Lab был ссылкой с собственным href и обработчиком show(), что могло увести из оболочки. Теперь обычный маршрут iframe.
- Межредакторные ссылки распознавались только под /chernozerye/ и без index.html. Теперь используется один resolver относительно расположения Studio.
- Два независимых списка открытия редакторов и устаревшее описание пяти модулей. Убран дублирующий набор карточек, маршруты сохранены, меню сгруппировано.
- Два узких внутренних скролла у истории и Roadmap. Теперь отдельные панели с общим скроллом рабочей области; данные и экспорт в своём разделе.
- Geo Lab утверждал, что исполнение квестов только планируется, хотя CI проверяет импорт и сценарии. Надпись заменена.
- «ГОТОВ» по событию iframe load не гарантирует работоспособность модуля. Используется «ОТКРЫТ».
- Снимок v1 экспортирует несколько черновиков и библиотеку; проверка из файла только запускает квестовый режим, ограничение 2,5 МБ. Это не полное восстановление, не синхронизация и не публикация. Пояснение добавлено в UI; схему не менять в этом пакете.
- Внутренние редакторы пока имеют разный UI, независимые команды импорта/экспорта, собственные 3D/картографические представления и старые маршруты. Не удалять функции, пока не проверены вызывающие модули, сохранения и регрессии. Существующие дополнительные инструменты сохранены для совместимости; новый функционал им не добавляется.
