# World Editor → Godot: индивидуальные постройки

В существующий build-time baker добавлено запекание индивидуальных building appearance из manual_layout.json. Конвертер GeoJSON уже валидирует рецепт. Поля нормализуются, хешируются SHA-256 (24 hex chars), одинаковые конфигурации используют один GLB; различие только в условии забора не создаёт отдельную модель дома. Модель запекается тем же кодом Studio и существующим объединением мешей/атласом. Базовые 37 моделей сохранены. Временный лимит — 64 уникальных дополнительных рецепта на сборку; превышение явно останавливает сборку, не заменяет авторские настройки молча. Это инженерный бюджет до измерений размера PCK/памяти, не утверждённый лимит дизайна.

Manifest appearance_models.json связывает ID геообъекта с GLB, этажностью, состоянием окон и исходным рецептом. Godot сверяет точное соответствие рецепта и наличие ресурса, при несовпадении предупреждает и использует базовую модель. Существующие проверка свободного места, автоматическое определение фасада, размещение, чанки и MultiMesh сохранены; этажность влияет на высоту существующего коллайдера, индивидуальное состояние окон определяет добавление света дома. Рецепт не является точной командой размещения: алгоритм может сместить/уменьшить постройку либо не поставить её при отсутствии безопасного места. Коллизии остаются приближёнными стенами, не полной коллизией каждой детали. Внешний вид проходит через существующие материалы, освещение и PS1-эффекты Godot.

## Workflow
World Editor → выбрать дом → Настроить в 3D → Применить → Экспорт всей карты → проверить GeoJSON и заменить исходный survey в репозитории в отдельном PR → конвертер → bake → импорт Godot → Web CI. Локальный браузерный черновик сам по себе не меняет опубликованную игру. Существующая опубликованная карта без индивидуальных рецептов остаётся неизменной. Не заменяем авторский survey тестовыми данными.

CI: отдельный fixture трёх домов с двумя рецептами, запекание только custom GLB в отдельный тестовый каталог, проверка manifest, импорт, тест реального выбора и MultiMesh, удаление тестового каталога до экспорта. Обычные регрессии деревни/физики сохраняются. Окончательная визуальная приёмка и измерение нагрузки нужны после импорта авторского GeoJSON. Природа, высота, точный поворот, runtime playtest браузерных черновиков и полноценный 3D-редактор остаются следующими пакетами.
