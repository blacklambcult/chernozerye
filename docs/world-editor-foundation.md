# World Editor — первая интеграция Geo Lab и генераторов

Roadmap 3.0: пакеты World Components / Studio. Geo Lab остаётся владельцем геометрии и стабильного ID. Building/Nature Generator остаются владельцами визуального рецепта и 3D-предпросмотра. Один новый необязательный атрибут properties.appearance версии 1 в GeoJSON; старая схема и хранилище не меняются. Конвертер переносит валидный рецепт в manual_layout.json, но Godot пока не использует его при создании объектов.

## Реализовано
- Выбор объекта из опубликованной игровой карты с явным копированием в локальный черновик по его ID. Географическая подложка OSM/Overture остаётся справочной.
- Трансформация контура/линии/точки: относительные смещения восток/север в метрах, вращение по часовой стрелке вокруг среднего значения вершин, масштаб. Используется локальное приближение, координаты остаются WGS84.
- Встроенный диалог существующего генератора, загружаемый только при открытии. Тип фиксирован по категории (дом/сарай/баня/лес/вода), сохранённый рецепт восстанавливается, результат применяет только явная кнопка внешнего диалога. Сохранение в библиотеку и размещение в Quest в этом режиме скрыты. При закрытии iframe освобождается. Не создаются новые GLB.
- Лес: рецепт образца дерева, не плотность/состав зоны. Вода: рецепт образца тайла, не рендер всего водоёма. Остальные категории пока только геометрия.
- Экспорт черновика и отдельный экспорт полного опубликованного мира с локальными переопределениями по ID. Удаление черновика не удаляет опубликованный объект; удаление объектов базового мира потребует отдельного механизма.

## Проверка
Открыть Geo Lab в Studio, кликнуть дом актуальной игровой карты, подтвердить копирование. В инспекторе «Настроить в 3D», выбрать крышу/стены/этажность, применить. Повторно открыть — параметры должны восстановиться; отмена не меняет рецепт. Смещение +10 м на восток и поворот 15° изменяют контур, ID тот же. Повторить для леса. Экспорт всей карты сохраняет все исходные ID и новые настройки. Проверить JSON после перезагрузки. Проверить обычный режим генераторов отдельно.

## Границы
Не реализован общий 3D-мир, индивидуальные деревья/заборы, высота объекта в Godot, автоматическая публикация или применение визуальных рецептов в runtime. Следующий пакет: импорт рецептов в фактическую геометрию и общие ресурсы Godot, проверка коллизий/чанков, кеширование одинаковых конфигураций, затем массовое редактирование и зоны природы. До реальной проверки не повышать готовность Roadmap.
