# Studio: визуальная реорганизация рабочих областей

База main 62821cd6; Roadmap 3.0, пакет 15. Предыдущий пакет улучшил маршруты и контекст, но почти не изменил внешний вид внутренних редакторов. Эта итерация меняет структуру интерфейса, не Godot runtime и не формат проектов.

## Изменения
- Geo Lab: три области. Слева авторские объекты, игровая разметка, справочные слои, подложка и область; в центре карта и инструменты рисования; справа свойства выбранного объекта, справочный инспектор, импорт/экспорт. Поиск по названию/ID/типу и постраничный список (100 строк, без изменения исходных данных). При узком viewport карта и панели переходят в вертикальную/двухколоночную компоновку. Ссылки на остальные редакторы скрыты внутри Studio, но сохранены для самостоятельной страницы; источники картографических данных видимы.
- Quest Lab: горизонтальные вкладки Сценарии, Записки, Предметы, Персонажи, Размещения. Последние отделены от предметов; выбранный экземпляр редактируется в правом инспекторе, список и модель-пикер остаются слева. Карточки персонажей вынесены в правый инспектор. Режим просмотра и проверка контекста сохранены. Существующий переход из генераторов с model ID открывает раздел размещений, а при уже загруженном редакторе вызывает его интерфейс без перезагрузки iframe (с подтверждением отмены незаконченного размещения).
- Библиотека ассетов в центре управления: читает существующий ChernoObjectLibrary IndexedDB models/placements, показывает названия, ID, источник, тип, размер GLB и число экземпляров. Поиск и фильтры, диагностика размещений без модели, страничный вывод по 40. Загружается по открытию вкладки. Не новая БД, не каталог ресурсов из Git/Godot, не редактор модели и не механизм публикации; записи не изменяются. Предпросмотр и редактирование остаются у редакторов.
- Общий UI kit workbench.css: визуальные токены, кнопки, состояния, поля, адаптивные рабочие области Geo и Quest. Studio получила согласованную палитру и закреплённые вкладки. Остальные генераторы пока без перевёрстки.

## Данные
Сохранены существующие ID и обработчики, новые интерфейсные ID добавлены только для фильтрации/инспекторов. GeoJSON, Quest Lab v1, localStorage, IndexedDB, игровой импорт, release history и Roadmap без миграций. Никаких удалений пользовательского контента. Фильтрация Geo списка не скрывает геометрию карты. Каталог ассетов не хранит вторые копии GLB.

## Приёмка
1. Desktop: открыть Geo Lab через Studio, убедиться в трёх областях. Выбрать объект, проверить поиск, фильтр и следующие 100 строк. В режиме редактирования сохранить свойства и вершины; экспортировать GeoJSON.
2. Quest Lab: проверить пять вкладок; создать/выбрать запись в сценариях, записках или предметах. Сменить раздел на «Размещения» — найти модель, выбрать существующий экземпляр, проверить правый инспектор, сохранение и отмену. Проверить карточку персонажа.
3. Вернуться в Studio и открыть библиотеку: сверить модели и число экземпляров, фильтры, поиск, отсутствие записи новых данных. Переход из генератора в открытый Quest Lab не должен сбрасывать iframe.
4. Проверить узкий viewport и отдельно открытые редакторы, переключение бокового меню, локальные файлы, журнал и Roadmap.

Проверки в коде: tests/studio-workbench.test.cjs (каталог, DOM, изоляция контекста), tests/studio-shell.test.cjs (переходы и каталог). Полный Web CI отдельно; реальный браузерный smoke-test обязателен для визуальной приёмки. Roadmap: проценты не меняются до выполнения соответствующих критериев.
