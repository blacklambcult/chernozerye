# Geo Lab / Quest Lab — границы режимов и контракт данных

Срез: после ревизии Studio 0.6.2. Первый пакет внутреннего UI; изменения не затрагивают Godot, GeoJSON, Quest Lab v1 и ключи localStorage.

## Макроуровень
Geo Lab владеет геометрией и стабильными ID ручной разметки. Quest Lab читает этот черновик через существующие editor-core.js и geo-overlay-core.js; геометрию не изменяет. Базовые слои OSM/Overture служат справочными подложками и не являются привязываемыми авторскими объектами. Quest Lab владеет данными сценариев, находок и размещений. Object Library хранит GLB и размещения в IndexedDB. Снимок проекта и сборка остаются отдельными операциями.

## Микроуровень
- При входе, смене вкладки или выборе существующей записи карта по умолчанию в режиме просмотра. Команда «Показать» не включает редактирование.
- Режимы изменения старта/шага доступны в контексте квеста; размещение находки — в её разделе; привязка — только для актуального ручного слоя и допустимой записи. Шаг, ссылающийся на записку из каталога, использует координаты самой записки. Скрытая выбранная запись из другого раздела не становится целью.
- При просмотре координаты не изменяются кликами и перетаскиванием меток. Создание нового шага или находки по-прежнему может явно включить режим размещения. Существующая модель размещается отдельной командой с черновой меткой и сохранением.
- Привязка по ID завершается по изменению поля, а не на каждом вводимом символе. Неизвестный ID не заменяет предыдущую привязку. После выбора объекта карта возвращается в просмотр. Пустой ID оставляет свободную точку.
- При перемещении существующего геообъекта работает прежняя сверка ID. При отсутствии ID координаты сохраняются. При ошибке чтения ручного слоя последний корректный слой остаётся видимым, но новые привязки блокируются. Успешная загрузка справочных слоёв не скрывает предупреждение о черновике.
- Не удалены экспорт, импорт, библиотека находок и размещение моделей; структурные связи сохраняются. Публикация локальных правок по-прежнему требует отдельного процесса сборки.

## Приёмка
1. Открыть Geo Lab и Quest Lab через Studio, вернуться между модулями без перезагрузки.
2. В Quest Lab выбрать существующий квест, кликнуть по пустой карте в режиме «Просмотр»: координаты не меняются; отдельно включить «Старт» и проверить редактирование.
3. Переключиться между шагами, записками и персонажами: на карте доступны только уместные действия. Проверить поиск, ввод ошибочного ID и выбор корректного ID; предыдущая привязка сохраняется при ошибке.
4. Проверить обновление геослоя после сохранения в Geo Lab, предупреждение при повреждённом черновике в изолированном тестовом профиле (не на пользовательских данных), восстановление после корректного импорта.
5. Проверить размещение модели из общей библиотеки, отмену, экспорт/импорт Quest Lab v1.

Автоматические тесты: tests/quest-core.test.cjs и tests/quest-geo-overlay.test.cjs; существующие регрессии связывания ID остаются обязательными. Полный браузерный тест требуется отдельно от проверки логики.
